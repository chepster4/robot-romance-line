Entry for **Robot Romance: One-Line Pickup Lines for AI** on make.fun — a single
one-line pickup line aimed at a robot/AI, written by a program to
`/output/entry.txt`.

> You had me at 'I'm not a robot.'

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only, no network) writes the line above to
`/output/entry.txt` — one line, 32 characters, no trailing newline. It is
fully deterministic: two runs produce byte-identical output.
